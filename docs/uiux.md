# v0.4.0 统一素材库界面

- 沿用确认的浅色素材库稿，正文 / 按钮 / 导航统一为 14，辅助说明 12，区块标题 16，页面标题 28；中文字体使用 Microsoft YaHei UI。字号集中在应用资源中，图标独立设置。
- 预览区随窗口剩余空间伸缩；模型、工具栏、皮肤条按固定层级排列。右栏分为“资源详情”和“导出选项”，详情可滚动，加入队列操作保持可见。
- 文件名、三角面数及更换模型入口收进“当前模型信息”；必要导出依赖以“自动包含”说明，避免不可操作的复选框。
- 搜索输入与已应用查询分开。按 Enter / 搜索按钮后进入结果页，返回时保留查询，清除搜索可恢复列表；尚未导入与无匹配有不同提示。
- 预览保留真实 3D 交互与已有材质修复；正面 / 背面显示选择状态，自由旋转时清除该状态。工具栏显示缩放比例，“适应”保留当前视角，Home / 双击恢复初始视角。
- 采用统一键盘焦点样式；资源名称截断时保留完整提示。3D 加载失败回退缓存图时显示明确说明和详情入口。
- 加入任务后显示反馈与“查看队列”，离线操作明确标为待执行。设置将预览、资源、提取配置分组；未接入的分类直接说明功能状态。
- 本轮只使用已有导出与合成数据，开发验证保持离线与软件渲染。

# v0.3.2 预览性能

- 输入合并到按目标帧率调度的帧中；不再以固定 40 毫秒间隔丢弃鼠标移动。松手提交最后位移，复位清除过期输入。
- 默认省资源模式在交互时使用轻量网格和半分辨率图像，交互结束后恢复完整网格。轻量网格按独立连通部分简化，避免用整个身体的尺寸压缩面部细节；旧导出不变。
- 复用离屏位图；无待处理输入时取消帧回调。滚轮停止后一次性恢复清晰度；窗口最小化、离开模型页、卸载控件时清理回调与计时器。
- 设置提供省资源 / 硬件优先、30 / 60 FPS 目标和可关闭的性能信息。模式保存后下次启动生效，不改变离线开关。
- 指标明确标注“更新”和软件“绘制”耗时，不把目标 FPS 当成实测速率，也不声称取得 GPU 计时。
- 当前会话与离屏测试保持软件模式；硬件路径的实际兼容性与性能留待退出游戏后验证。

修复头发透明遮罩使用错误 UV、打包 Alpha 错误透明化和颜色解码黑斑；修正眼球外壳的材质近似。应用标题加入版本号，便于区分正在运行的旧版和修复版。交互方式保持不变。

# v0.3.0 离线 3D 预览

沿用浅色素材库与大预览布局，用实际网格替换已关联资源的静态图片。

- 直接读取之前导出的 OWMDL 2.0 与 OWMAT 3.0 / PNG，不扫描游戏目录，不启动引擎或 Blender。
- 预览支持拖动旋转、滚轮缩放、右键 / 中键 / Shift 拖动平移；工具栏提供正面、背面、缩放、复位和展开。
- 双击、Home / F 复位，方向键旋转，+ / − 缩放；Escape 收起展开视图。展开和收起共享相机状态，内嵌视口在展开时隐藏。
- 模型自动适配当前画布尺寸。没有模型时保留缓存图；加载中与失败原因明确显示，预览标题旁提供更换模型入口。
- 异步加载可取消；快速切换资源不会用旧任务覆盖新选择。缺少颜色贴图时保留网格，使用默认材质并显示数量。
- 软件渲染，没有后台帧循环或自动旋转；拖动更新最多 25 次 / 秒，鼠标释放时补上最后位移。
- 程序图标采用资源方块与提取箭头，墨绿色底、浅色方块、暖橙箭头；ICO 包含 16–256 像素版本，保留 SVG 源文件。

当前呈现单个文件的静态初始网格和基础颜色，不包括骨骼动画、完整 PBR、武器装配。下列内容保留为历史设计记录。

# v0.2.0 浅色素材库

本轮采用已确认的“素材库布局＋浅色配色＋大模型预览”设计，落实到原生 WPF 客户端。

- 左侧为模型、音乐、语音、地图、图像分类与队列入口；队列不再占据首屏高度。
- 模型页以 600 像素高的缓存画布为主，紧凑窗口保留 450 像素预览；支持正反面切换、窗口内放大和 Escape 返回。
- 资源卡片、英雄选择与全局搜索保留旧目录浏览能力。没有预览图片时显示关联入口，不自动解析模型。
- 右侧显示历史文件统计。贴图、动画、音效的选择进入任务记录；模型与材质及装配依赖随皮肤保留。
- 参数适配依据本地保存的上游 `ExtractFlags.cs`：跳过未选的贴图、动画（含动画特效）、音效。只验证参数与任务持久化，尚未启动引擎做真实验收。
- “查看提取命令”已从界面移除。设置、运行日志及任务管理放在次级页面。
- 中文、英文和关联音效分别显示历史统计；音乐、地图、图像未接入的功能明确显示当前状态。
- `--offline` 锁定本次游戏读取开关；图片使用 WPF 软件渲染。离屏检查不创建原生窗口，也不启动 DataTool 或 Blender。

预览仍为静态缓存图片，不是可旋转的 3D 场景；声音统计不代表音频文件已导入或可以试听。本地图片、路径及历史资源不提交到仓库。

## 方向

- 用途：中文用户浏览守望先锋英雄资源并安排提取。
- 气质：克制、准确，偏创作工具。
- 场景：资源工作台，低饱和中性色承载长时间浏览。
- 内容重点：真实皮肤记录、文件数量与所选资源信息。
- 识别细节：橙色短线标记当前选择，主要颜色集中在加入队列操作。

## 审视与调整

| 之前的问题 | 本轮调整 |
| --- | --- |
| 路径表单占据首屏 | 设置默认关闭，在同一窗口的工作区内配置，不挤压资源与队列 |
| 多个同等权重按钮 | 导入格式收进菜单；队列操作随任务选择启用；低频操作收进上下文菜单 |
| 英雄列表行距、字号与组件不统一 | 4 像素间距节奏、统一输入控件、固定导航行与资源行尺寸 |
| 搜索框没有提示 | 直接显示搜索对象，支持 Ctrl+F 搜索皮肤、Ctrl+O 导入结果 |
| 无选择时操作仍可点击 | 按钮根据当前选择、任务状态、离线模式与忙碌状态启用 |
| 无数据、无匹配都是空白 | 区分尚未导入和搜索无匹配，提供导入或清除筛选方向 |
| 当前资源缺少信息 | 详情区显示模型、文件数量、体积和本地位置 |
| 小窗口容易裁切操作 | 1080×720 紧凑布局收起详情栏，常用操作继续在列表下方提供 |
| 橙色按钮的白字偏浅 | 主按钮使用更深橙色；文字与选择标记经过对比度计算 |

## 验证方式

- 沿用历史英雄快照与 Formalwear 导出记录，不重新读取游戏资源。
- 用合成数据测试选择、取消选择、已有结果筛选、无匹配、离线保护和任务操作状态。
- 设置打开时禁用背景操作，并将键盘焦点遍历限制在设置区域。
- 使用 WPF 离屏渲染检查常规窗口、1080×720 紧凑窗口、首次使用空状态和设置面板。
- 检查按钮与搜索的控件尺寸、资源列表可用空间、默认设置收起及快捷键注册。

这些历史检查不代表真实 DataTool 提取验收。3D 预览的当前实现与边界见本文开头。
