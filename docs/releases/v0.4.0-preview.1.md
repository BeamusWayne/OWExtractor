# OWExtractor v0.4.0-preview.1

中文 Windows 资源客户端开发预览。本版集中改进已有导出的浏览、3D 预览和素材库交互。

## 更新内容

- 统一浅色素材库的字体层级、控件尺寸与间距；模型预览随窗口伸缩。
- 分离“资源详情”和“导出选项”，保持队列操作可见；搜索按 Enter 提交并保留结果条件。
- 直接预览已有 OWMDL 模型和颜色贴图，支持旋转、缩放、平移、正反面切换和展开。
- 修正头发第二套 UV、透明边缘、眼睛及打包 Alpha 的显示；模型失败时明确提示缓存图回退。
- 合并旋转输入，软件交互时使用轻量预览，结束后恢复完整模型。新增硬件优先设置、目标帧率和性能信息。
- 默认离线启动；历史资源导入、任务选择、离线队列与运行日志保持独立。

## 下载与运行

下载并解压 `OWExtractor-win-x64.zip`，运行 `OWExtractor.exe`。自包含包无需另装 .NET；提供 `.sha256` 文件核对下载内容。

游戏运行期间可使用：

```powershell
.\OWExtractor.exe --offline --software --no-activate
```

此方式锁定本次离线与软件渲染，打开窗口时不主动切换焦点。导入自己已有的导出目录、模型或历史 JSON；发布包不含游戏资源、个人配置或 DataTool 引擎。程序未进行代码签名。

## 验证范围与限制

- 22 项核心检查、合成数据离屏界面检查及自包含包启动检查通过；本地另对历史导出执行了 16 组界面检查。
- 已验证的主要能力是离线浏览、静态 3D 预览、界面交互和任务记录；这些检查不等于真实提取成功。
- 当前游戏版本识别、DataTool 兼容性、真实单项 / 批量提取、GPU 模式性能及独立 Windows 设备验收仍待完成。
- 不提供完整 PBR、实体 / 武器自动装配、动画播放或音频试听；音乐、地图和图像分类的文件浏览尚未接入。
- 软件模式的实际交互速率受模型和系统负载影响，30 / 60 FPS 为目标值；硬件模式建议退出游戏后使用。
