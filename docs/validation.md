## v0.3.1 材质修复

v0.3.0 的可旋转预览曾出现头发缺块、眼睛被覆盖和颜色黑斑。原因包括：只保留首套 UV、把打包 Alpha 当作透明度，以及 WPF 缩放时预乘 Alpha 导致颜色通道丢失。v0.3.0 的交互检查未覆盖这些材质问题。

- 保留第二套 UV；根据本地 io_scene_owm 的 OW2 头发规则，将其用于透明遮罩，颜色继续使用首套 UV。
- 加载时对头发透明边缘做有界网格裁切，避免透明像素写入深度造成层间遮挡。旋转时不重做此步骤。
- PNG 保留独立 RGB / Alpha 通道后再缩放；普通颜色与眼睛的打包 Alpha 不再造成孔洞。玻璃、折射外壳用低强度高光近似，复杂材质提供基础颜色。
- 17 项核心检查通过；新增第二套 UV 与颜色 UV 独立性、透明边缘几何有效性和源数据不变检查。离屏界面检查新增完全透明区域仍保留 RGB 的 PNG 回归样例。
- 历史正装源网格仍为 60,465 三角面，透明边缘处理后渲染 72,765 三角面；6 张颜色贴图，默认材质网格由 2 个降至 0 个。
- 打包程序检查正面、侧面、背面、展开、头部特写、紧凑尺寸与异常回退。软件渲染、离线锁定、无引擎进程、无可见测试窗口；测试没有改变前台焦点。
- 仍是基础材质预览，不包含完整 PBR、真实折射或骨骼动画。没有修改旧导出或读取游戏存储。
