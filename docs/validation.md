## 自动检查

核心检查包括：

1. 英雄 JSON 校验与 GUID 中文名称合并。
2. 扁平及嵌套皮肤 JSON 解析和去重。
3. 旧导出文件统计及源文件保持不变。
4. 中文、空格和末尾反斜杠的参数边界。
5. 离线模式在文件访问与进程启动前拒绝调用。
6. 游戏运行、进程状态未知时拒绝调用。
7. 使用测试程序自身子进程验证 stdout、stderr 和参数往返。
8. 使用测试子进程验证取消。
9. 设置持久化且不保存游戏读取许可。
10. 已知错误的中文解释。

界面通过离屏 WPF 渲染检查布局，并验证旧数据导入、搜索、加入队列与离线执行拒绝。离屏检查不创建可见窗口，不改变游戏焦点。

v0.1.1 进一步检查未选择时禁用加入队列、多选计数、无匹配状态、仅已有结果筛选、任务操作条件、设置面板隔离，以及 1360×960 和 1080×720 两种尺寸。界面改进说明见 [UI/UX 说明](uiux.md)。
